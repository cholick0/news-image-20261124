## How it works

`entry.png` (1024×1024) was rendered in this session with Python PIL
(`draw.py`). `main.ts` (Node 22) copies it to `/output/entry.png` and
verifies it is a whole 1024×1024 PNG under the 1 MiB limit.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
